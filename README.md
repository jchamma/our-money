# הכסף שלנו

תזרים המזומנים של RiseUp, ועוד דבר אחד: **פרויקטים**.

RiseUp מערבב הוצאות חד־פעמיות (טיול, שיפוץ, אירוע) בתוך התזרים החודשי, ואז התחזית של החודש מפסיקה להיות אמינה. כאן מעבירים הוצאה או הכנסה כזו לפרויקט: היא יוצאת מהתזרים השוטף ונספרת רק בתוך הפרויקט. לכל פרויקט יש קטגוריות משלו, תכנון חודשי לכל קטגוריה ותחזית לסוף החודש.

- **מסך הבית:** איך צפוי להסתיים החודש השוטף, באותם חלקים של RiseUp (משתנות, קטגוריות במעקב, קבועות, הכנסות), וסיכום של השוטף, כל פרויקט והסך הכול.
- **העברה לפרויקט:** נוגעים בתנועה, בוחרים פרויקט, וזהו. אפשר לבקש שתנועות עתידיות מאותו בית עסק יעברו לשם אוטומטית.
- **לשניים:** עד שני אנשים בכל התקנה, שניהם רואים ועושים הכול.
- **על הטלפון:** אפליקציית רשת שמתקינים למסך הבית, בעברית.

> **לא רשמי.** הפרויקט הזה לא קשור ל־RiseUp ולא מאושר על ידה. הוא קורא את הנתונים שלכם דרך ה־API הציבורי של RiseUp, בהרשאת קריאה בלבד, ולא משנה שום דבר בחשבון שלכם.

## איך זה עובד

כל זוג מתקין עותק פרטי משלו על חשבון Cloudflare משלו. אין שרת משותף, ואף אחד מלבדכם לא רואה את הנתונים.

- **חינם:** הכול רץ על התוכנית החינמית של Cloudflare (Workers + D1). לא צריך כרטיס אשראי.
- **תמיד מעודכן:** בכל פתיחה האפליקציה מושכת מ־RiseUp את החודש הקודם והנוכחי (וגם בכל לילה, ליתר ביטחון).
- **גרסאות חדשות מותקנות לבד:** מאגר פרטי בחשבון ה־GitHub שלכם בודק כל 3 שעות אם יצאה גרסה חדשה ומתקין אותה. הנתונים שלכם לא עוברים ל־GitHub.
- **טוקן RiseUp:** תקף ל־30 יום. כשהוא עומד לפוג, האפליקציה מבקשת טוקן חדש ומחדשים אותו ישר מהטלפון.

## איך נכנסים

בוחרים שיטה אחת בזמן ההתקנה:

| | **Passkeys (מומלץ)** | Google | קוד במייל |
|---|---|---|---|
| איך נכנסים | Face ID או טביעת אצבע | חשבון Google | קוד בן 6 ספרות במייל |
| חשבונות נוספים לפתוח | **אף אחד** | Google Cloud | Brevo (שליחת מיילים) |
| צעדים נוספים בהתקנה | **0** | כ־10 דקות | כ־10 דקות |
| מדריך | [setup-passkeys](docs/setup-passkeys.md) | [setup-google](docs/setup-google.md) | [setup-email](docs/setup-email.md) |

**Passkeys הן הדרך הפשוטה ביותר, בהרבה.** אין סיסמה, אין חשבון נוסף ואין מה להגדיר: בסוף ההתקנה מקבלים קישור אישי לכל אחד, פותחים אותו בטלפון, והטלפון שומר מפתח כניסה שנפתח ב־Face ID או בטביעת אצבע. בחרו Google או מייל רק אם יש לכם סיבה.

## התקנה

צריך מחשב (Windows, Mac או Linux), כ־20 דקות, ו:

1. [Node.js](https://nodejs.org) גרסה 20 ומעלה (LTS).
2. חשבון Cloudflare (חינם, בלי כרטיס). אפשר לפתוח אותו תוך כדי ההתקנה.
3. טוקן RiseUp עם הרשאת קריאה (`budget:read`).
4. חשבון GitHub (חינם), לעדכונים האוטומטיים. אפשר לפתוח אותו תוך כדי ההתקנה. ב־Mac צריך גם את [GitHub CLI](https://cli.github.com); ב־Windows ההתקנה מתקינה אותו לבד.

ואז, לפי השיטה שבחרתם: **[המדריך ל־Passkeys](docs/setup-passkeys.md)** (מומלץ), [המדריך ל־Google](docs/setup-google.md) או [המדריך לקוד במייל](docs/setup-email.md).

אחרי ההתקנה:

| פקודה | מה היא עושה |
|---|---|
| `node scripts/auto-update.mjs` | מפעילה עדכונים אוטומטיים (ההתקנה מציעה את זה). אפשר להריץ שוב כדי לתקן או להחליף את טוקן Cloudflare. |
| `node scripts/update.mjs` | מתקינה גרסה חדשה ידנית (אחרי שמורידים את הקוד מחדש לאותה תיקייה), ומציעה להפעיל עדכונים אוטומטיים. הנתונים נשארים. |
| `node scripts/add-person.mjs` | נותנת גישה לאדם נוסף, או לטלפון חדש (עד שני אנשים). |
| `node scripts/remove-person.mjs` | מבטלת גישה. האדם מנותק מיד מכל המכשירים. |

## אבטחה

- **הנתונים שלכם אצלכם:** הם נשמרים רק במסד הנתונים (D1) בחשבון Cloudflare שלכם.
- **טוקן RiseUp מוצפן:** הוא נשמר מוצפן (AES-256-GCM). מפתח ההצפנה נשמר כסוד של Cloudflare, בנפרד מהנתונים, והטוקן לא נשלח אף פעם לדפדפן.
- **רק שניכם:** אפשר להירשם רק עם קישור הזמנה חד־פעמי (Passkeys) או עם אחד משני המיילים שהוגדרו (Google, מייל). אי אפשר להוסיף אדם שלישי.
- **בלי צד שלישי:** אין אנליטיקס, אין פרסומות ואין פונטים או סקריפטים מאתרים אחרים. Google ו־Brevo מקבלים פנייה רק בשיטת הכניסה שלהם, ורק לצורך הכניסה.
- **נכשל בצורה סגורה:** אם משהו בהגדרות חסר, האפליקציה לא מציגה כלום.
- **עדכונים אוטומטיים:** המאגר `our-money-updates` בחשבון ה־GitHub שלכם הוא פרטי, ומכיל רק את קובץ העדכון. ב־GitHub Secrets נשמרים טוקן Cloudflare (הרשאות Workers ו־D1 בלבד) והגדרות ההתקנה. הוא מתקין את הגרסה האחרונה מהפרויקט הזה, וקוד שמותקן ככה יכול לגשת לכל מה שהאפליקציה ניגשת אליו, כולל הנתונים. כלומר, הפעלה שלו היא אמון בפרויקט, בדיוק כמו התקנה ידנית של גרסה חדשה. לפני כל עדכון נרשמת נקודת שחזור של D1 Time Travel (7 ימים אחורה בתוכנית החינמית). כדי להפסיק: מוחקים את המאגר.
- **מה פומבי:** מסכי האפליקציה הם קבצים סטטיים, פומביים כמו הקוד ב־GitHub. כל פיסת מידע עוברת דרך `/api`, שדורש כניסה.

מצאתם בעיית אבטחה? דווחו עליה בפרטיות דרך **Security › Report a vulnerability** בדף הפרויקט ב־GitHub, ולא ב־issue פומבי.

## פיתוח

```bash
npm install
npm run dev                 # האפליקציה וה־API מקומית
bash scripts/validate.sh    # tsc + כל הבדיקות
```

הקוד: `src/` (ה־Worker: API, התחברות, סנכרון), `web/` (האפליקציה), `migrations/` (מסד הנתונים), `scripts/` (התקנה).
