# התקנה עם קוד במייל

כל אחד מקבל קוד בן 6 ספרות למייל שלו. את המיילים שולח Brevo, שירות שליחה עם תוכנית חינמית (300 מיילים ביום). זה כ־10 דקות יותר מ־[Passkeys](setup-passkeys.md). **אם אין לכם סיבה מיוחדת, Passkeys פשוטות יותר.**

## 1–3. Node.js, הקוד וטוקן RiseUp

עושים את שלבים 1, 2 ו־3 מ[המדריך הזה](setup-passkeys.md), ואז חוזרים לכאן.

## 4. פותחים חשבון Brevo

1. נרשמים ב־[brevo.com](https://www.brevo.com) לתוכנית **Free** ומשלימים את פרטי החשבון.
2. **כתובת שולח:** בתפריט **Senders, Domains & Dedicated IPs › Senders › Add sender**. מזינים שם (`הכסף שלנו`) וכתובת מייל שלכם, ומאשרים עם הקוד ש־Brevo שולח אליה.
3. **מפתח API:** **SMTP & API › API keys › Generate a new API key**. קוראים לו `our-money` ומעתיקים אותו. הוא מוצג פעם אחת בלבד.
4. **כתובות IP:** אם יש בחשבון הגדרה בשם **Authorized IPs** (תחת **Security**), מבטלים את החסימה של כתובות לא מוכרות. האפליקציה שולחת מהשרתים של Cloudflare, שהכתובות שלהם משתנות.

## 5. מריצים את ההתקנה

```
npm run setup
```

| השאלה | מה עונים |
|---|---|
| חלון דפדפן של Cloudflare | נכנסים או נרשמים (חינם, בלי כרטיס) ולוחצים **Allow**. |
| `How will you log in?` | `3` (קוד במייל). |
| `How many people` | `2` לזוג, `1` אם רק אתם. |
| `Person 1: email` | המייל של כל אחד. **רק הכתובות האלו יקבלו קוד.** |
| `Brevo API key (hidden)` | מדביקים את המפתח משלב 4. ההתקנה בודקת אותו מול Brevo. |
| `Send codes from` | כתובת השולח שאישרתם בשלב 4. |
| `RiseUp token (hidden)` | מדביקים את הטוקן ולוחצים Enter. |
| `Name for this copy` | Enter, או שם באנגלית קטנה. |
| `Your database may not be available… continue?` | `y` ו־Enter. זה מסד הנתונים החדש והריק שלכם. |

**הצלחה:**

```
[7/7] Open the app
  Open https://our-money.<שם>.workers.dev on your phone and log in with …
  Done.
```

## 6. נכנסים מהטלפון

1. פותחים את הכתובת בטלפון, כותבים את המייל ולוחצים **שליחת קוד**.
2. מקלידים את הקוד מהמייל. הוא תקף ל־10 דקות.
3. **בפעם הראשונה הקוד יכול להגיע לספאם.** מסמנים אותו "לא ספאם", והבאים יגיעו לתיבה.
4. כותבים את השם שלכם ולוחצים **המשך**.
5. מתקינים למסך הבית: ב־iPhone, שיתוף › **הוספה למסך הבית**; ב־Android, ⋮ › **התקנת אפליקציה**.

## אחר כך

- **להוסיף או להחליף אדם:** `npm run add-person` / `npm run remove-person`.
- **גרסה חדשה:** `git pull` (או הורדה מחדש), `npm install`, `npm run update`.
- **כניסה נשמרת לשבוע.** אחר כך מבקשים קוד חדש.

## אם משהו לא עובד

| מה רואים | מה עושים |
|---|---|
| `Brevo didn't accept that key` | מעתיקים את המפתח שוב, או יוצרים חדש (שלב 4.3). |
| הקוד לא מגיע | בודקים בספאם. ב־Brevo, **Transactional › Logs** מראה אם המייל נשלח. אם הוא נחסם, בודקים את שלב 4.4. |
| "יותר מדי ניסיונות" | יש מגבלה על ניסיונות ושליחות. מחכים כמה דקות. אם זה נמשך עד מחר, ראו למטה. |
| הקוד לא מתקבל | רק הקוד האחרון שנשלח תקף. מבקשים קוד חדש ומקלידים אותו. |

## מגבלה ידועה

כדי שאי אפשר יהיה לנחש קוד, כל כתובת מייל מקבלת עד 20 ניסיונות ביום. מי שיודע גם את כתובת האפליקציה וגם את המייל שלכם יכול לבזבז את הניסיונות בכוונה. הנתונים נשארים מוגנים, אבל הכניסה במייל נחסמת עד למחרת. מי שכבר מחובר נשאר מחובר (עד שבוע). אם זה מטריד אתכם, Passkeys לא מושפעות מזה בכלל.
