# התקנה עם Passkeys (מומלץ)

כניסה ב־Face ID או בטביעת אצבע. אין סיסמה, ואין חשבון נוסף לפתוח. **כ־15 דקות, כולל הכול.**

## מה צריך

- מחשב עם Windows, Mac או Linux.
- טלפון עם Face ID או טביעת אצבע (iPhone עם iOS 16 ומעלה, או Android 9 ומעלה).
- חשבון RiseUp.

## 1. מתקינים Node.js

1. נכנסים ל־[nodejs.org](https://nodejs.org) ומורידים את גרסת **LTS**.
2. מתקינים עם כל ברירות המחדל.
3. פותחים חלון פקודות: ב־Windows מחפשים **Command Prompt** (שורת הפקודה) בתפריט התחל; ב־Mac מחפשים **Terminal** ב־Spotlight.

   ב־Windows חשוב להשתמש ב־Command Prompt ולא ב־PowerShell: ב־PowerShell הפקודות `npm` ו־`npx` נחסמות כברירת מחדל.
4. מקלידים `node --version` ולוחצים Enter.

   **הצלחה:** מופיע מספר גרסה, למשל `v22.11.0` (20 ומעלה).

## 2. מורידים את הקוד

1. מורידים את הקוד מ[הקישור הזה](https://github.com/jchamma/our-money/archive/refs/heads/master.zip) (או בדף הפרויקט ב־GitHub: **Code › Download ZIP**). הקובץ `our-money-master.zip` נשמר בתיקיית ההורדות.
2. פותחים את ה־ZIP (לחיצה ימנית › **Extract All**). נוצרת תיקייה בשם `our-money-master`, ובתוכה הקובץ `package.json`.
3. בחלון הפקודות נכנסים לתיקייה הזו: מקלידים `cd` ורווח, גוררים את התיקייה `our-money-master` לחלון, ולוחצים Enter:

   ```
   cd <התיקייה>
   ```

4. מתקינים את מה שהאפליקציה צריכה:

   ```
   npm install
   ```

   **הצלחה:** בסוף מופיעה שורה כמו `added 312 packages`. אזהרות (`warn`) הן בסדר.

## 3. מכינים טוקן RiseUp

1. נכנסים לחשבון RiseUp בדפדפן ופותחים את [עמוד הטוקנים למפתחים](https://input.riseup.co.il/developer/tokens).
2. יוצרים טוקן חדש עם הרשאת קריאה: **`budget:read`**.
3. מעתיקים אותו מיד: הוא מוצג פעם אחת בלבד, ומתחיל ב־`riseup_pat_`. עוד רגע תדביקו אותו בהתקנה.

הטוקן תקף ל־30 יום. כשהוא עומד לפוג, האפליקציה תבקש טוקן חדש, ותחדשו אותו ישר מהטלפון.

## 4. מריצים את ההתקנה

```
npm run setup
```

ההתקנה שואלת כמה שאלות. כל מה שבסוגריים מרובעים הוא ברירת המחדל: Enter מקבל אותה.

| השאלה | מה עונים |
|---|---|
| `CLOUDFLARE_API_TOKEN is set…` | מופיע רק אם הוגדר אצלכם טוקן כזה. Enter (כן). |
| חלון דפדפן של Cloudflare | נכנסים לחשבון Cloudflare, או נרשמים (חינם, בלי כרטיס), ולוחצים **Allow**. |
| `How will you log in?` | Enter: **1, Passkeys**. |
| `How many people` | `2` לזוג, `1` אם רק אתם. |
| `RiseUp token (hidden)` | מדביקים את הטוקן (לא יופיע על המסך) ולוחצים Enter. |
| `Name for this copy` | Enter, או שם באנגלית קטנה (למשל `our-money`). הוא יופיע בכתובת. |
| `Your database may not be available… continue?` | `y` ו־Enter. זה מסד הנתונים החדש והריק שלכם. |

ההתקנה יוצרת את מסד הנתונים, מעלה את האפליקציה ושומרת את הטוקן מוצפן. זה לוקח כ־2 דקות, ועל המסך רצות הרבה שורות. זה תקין.

אם מופיעה שאלה על **workers.dev subdomain**: מקלידים שם קצר באנגלית (למשל שם המשפחה) ולוחצים Enter. זה קורה רק בפעם הראשונה בחשבון Cloudflare חדש.

**הצלחה:** בסוף מופיעים כתובת האפליקציה וקישור אישי לכל אחד:

```
[7/7] Open the app
  Person 1:  https://our-money.<שם>.workers.dev/invite/…
  Person 2:  https://our-money.<שם>.workers.dev/invite/…

  Done.
```

## 5. נכנסים מהטלפון

כל אחד עם הקישור שלו. **כל קישור עובד פעם אחת, במשך 24 שעות.**

1. שולחים לעצמכם את הקישור (בוואטסאפ לעצמכם, במייל) ופותחים אותו **בטלפון**.
2. כותבים את השם שלכם, לוחצים **הפעלת כניסה ביומטרית**, ומאשרים ב־Face ID או בטביעת אצבע.
3. מתקינים למסך הבית:
   - **iPhone (Safari):** כפתור השיתוף › **הוספה למסך הבית**.
   - **Android (Chrome):** ⋮ › **התקנת אפליקציה**.

**הצלחה:** מופיע "הכל מוכן" עם השם שלכם, ואחריו התזרים. בפתיחה הראשונה האפליקציה טוענת את הנתונים מ־RiseUp, ומשם הם מתעדכנים בכל לילה.

מהפעם הבאה: פותחים את האפליקציה ולוחצים **כניסה עם Face ID** (או טביעת אצבע).

## אחר כך

- **טלפון חדש, או קישור שפג:** `npm run remove-person` ואז `npm run add-person` (מאותה תיקייה במחשב). מקבלים קישור חדש.
- **גרסה חדשה:** מורידים את הקוד מחדש לאותה תיקייה (או `git pull`), ואז `npm install` ו־`npm run update`.
- **שמרו את התיקייה.** הקובץ `wrangler.jsonc` שבה מחבר אותה להתקנה שלכם. אין בו סודות.

## אם משהו לא עובד

| מה רואים | מה עושים |
|---|---|
| `RiseUp didn't accept this token` | יוצרים טוקן חדש עם `budget:read` ומדביקים שוב. |
| `wrangler.jsonc already exists` | ההתקנה כבר רצה מהתיקייה הזו. לגרסה חדשה: `npm run update`. |
| `A database named … already exists` | עונים `n` ומריצים שוב עם שם אחר. |
| הקישור אומר "ההזמנה כבר לא בתוקף" | עברו 24 שעות, או שכבר השתמשו בו. `npm run add-person`. |
| הטלפון לא מציע כניסה | ה־passkey נוצר בטלפון אחר. `npm run remove-person` ואז `npm run add-person`. |

## כמה זה עולה

כלום. התוכנית החינמית של Cloudflare מספיקה בהרבה לשני אנשים. כדי לוודא: ב־Cloudflare נכנסים ל־**Manage Account › Billing**, וצריך להופיע **$0**.
