# התקנה: "הכסף שלנו"

**כמה זמן:** 15 דקות.
**מה צריך:** מחשב, טלפון וחשבון RiseUp.

עושים את השלבים לפי הסדר, אחד אחרי השני.

---

## שלב 1: מתקינים תוכנה אחת (Node.js)

1. פותחים את הקישור: **https://nodejs.org/en/download**
2. לוחצים על כפתור ההורדה הגדול.
3. פותחים את הקובץ שירד.
4. לוחצים **Next** ← **Next** ← **Next** ← **Install** ← **Finish**.

✅ **סיימתם את שלב 1.**

---

## שלב 2: מורידים את האפליקציה

1. לוחצים על הקישור: **https://github.com/jchamma/our-money/archive/refs/heads/master.zip**
2. קובץ בשם `our-money-master.zip` יורד למחשב.
3. פותחים את תיקיית **ההורדות** (Downloads).
4. לוחצים **קליק ימני** על `our-money-master.zip`.
5. בוחרים **Extract All** (חלץ הכל).
6. לוחצים **Extract** (חלץ).
7. נפתחת תיקייה. לוחצים פעמיים על התיקייות שבפנים, עד שרואים קובץ בשם `package.json`.

✅ **סיימתם את שלב 2. השאירו את התיקייה הזו פתוחה.**

---

## שלב 3: מקבלים קוד מ־RiseUp

1. פותחים את הקישור: **https://input.riseup.co.il/developer/tokens**
2. נכנסים לחשבון RiseUp שלכם.
3. יוצרים טוקן חדש.
4. מסמנים **`budget:read`**.
5. מעתיקים את הקוד **מיד**: הוא מופיע רק פעם אחת.

✅ **סיימתם את שלב 3. הקוד שמור אצלכם ב"העתק".**

---

## שלב 4: מתקינים

### פותחים חלון פקודות

**ב־Windows:**
1. חוזרים לתיקייה מסוף שלב 2 (זו שרואים בה `package.json`).
2. לוחצים על **שורת הכתובת** למעלה (השורה שמראה איפה התיקייה נמצאת).
3. מוחקים מה שכתוב שם, כותבים **`cmd`** ולוחצים **Enter**.
4. נפתח חלון שחור.

**ב־Mac:**
1. פותחים את **Terminal** (לוחצים ⌘ + רווח, כותבים Terminal ולוחצים Enter).
2. כותבים **`cd`** ורווח.
3. גוררים לחלון את התיקייה מסוף שלב 2.
4. לוחצים **Enter**.

### מעתיקים ומדביקים שתי פקודות

**פקודה ראשונה:**
1. מעתיקים את השורה הזו:
   ```
   npm install
   ```
2. מדביקים בחלון השחור (**קליק ימני** ב־Windows, או ⌘+V ב־Mac).
3. לוחצים **Enter**.
4. מחכים עד שמופיעה המילה `added`.

**פקודה שנייה:**
1. מעתיקים את השורה הזו:
   ```
   npm run setup
   ```
2. מדביקים בחלון השחור.
3. לוחצים **Enter**.

### עונים על השאלות

**בכל שאלה פשוט לוחצים Enter.** רק במקומות האלה עושים משהו אחר:

| כשרואים... | עושים... |
|---|---|
| נפתח דפדפן של **Cloudflare** | נרשמים (חינם, בלי כרטיס אשראי), או נכנסים אם כבר יש לכם חשבון. לוחצים **Allow**. חוזרים לחלון השחור. |
| `How many people` | **Enter** לזוג. כותבים `1` אם זה רק אתם. |
| `RiseUp token` | מדביקים את הקוד משלב 3 ולוחצים **Enter**. **לא תראו כלום על המסך, וזה בסדר.** |
| `continue?` | כותבים **`y`** ולוחצים **Enter**. |
| `workers.dev subdomain` | כותבים שם קצר באנגלית (למשל שם המשפחה) ולוחצים **Enter**. |

הרבה שורות ירוצו על המסך. מחכים בסבלנות, בערך 2 דקות.

✅ **סיימתם את שלב 4 כשרואים את המילה `Done.`** מעליה יופיעו קישורים כאלה:

```
Person 1:  https://our-money.....workers.dev/invite/.....
Person 2:  https://our-money.....workers.dev/invite/.....
```

**Person 1** בשבילכם. **Person 2** בשביל בן או בת הזוג.

## שלב 5: פותחים בטלפון

כל אחד עושה את זה בטלפון שלו, עם הקישור שלו.

1. שולחים את הקישור לטלפון (למשל בוואטסאפ לעצמכם).
2. פותחים אותו **בטלפון**.
3. כותבים את השם שלכם.
4. לוחצים **הפעלת כניסה ביומטרית**.
5. מאשרים עם Face ID או טביעת אצבע.
6. שמים את האפליקציה במסך הבית:
   - **iPhone:** לוחצים על כפתור השיתוף (ריבוע עם חץ למעלה) ← **הוספה למסך הבית**.
   - **Android:** לוחצים על ⋮ למעלה ← **התקנת אפליקציה**.

🎉 **זהו! האפליקציה מוכנה.**

מעכשיו פותחים אותה ממסך הבית ולוחצים **כניסה עם Face ID** (או טביעת אצבע).

## פעם בחודש

האפליקציה תבקש **לחדש**. לוחצים על זה, עושים שוב את שלב 3, ומדביקים את הקוד באפליקציה.

---

## משהו לא עבד?

| מה קרה | מה עושים |
|---|---|
| כתוב `RiseUp didn't accept this token` | עושים שוב את שלב 3 ומדביקים את הקוד החדש. |
| כתוב ש־`npm` לא מוכר (`is not recognized`) | עושים שוב את שלב 1. סוגרים את החלון השחור ופותחים אותו מחדש. |
| הקישור בטלפון כותב "ההזמנה כבר לא בתוקף" | פותחים חלון פקודות כמו בשלב 4, מדביקים `npm run add-person`, לוחצים Enter ומשתמשים בקישור החדש. |
| קיבלתם טלפון חדש | פותחים חלון פקודות כמו בשלב 4. מדביקים `npm run remove-person` ולוחצים Enter. אחר כך מדביקים `npm run add-person`, לוחצים Enter ופותחים את הקישור החדש בטלפון. |
| כתוב `wrangler.jsonc already exists` | האפליקציה כבר מותקנת. אין מה לעשות. |

**אל תמחקו את התיקייה משלב 2.** צריך אותה כדי להוסיף אדם או טלפון חדש.
